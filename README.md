# Tip Calculator

## Description

This project is a simple web-based **Tip Calculator** that allows users to calculate a tip on a bill and either split the total amount among friends or randomly select one friend to pay.

The application runs entirely in the browser and requires no external libraries.


## Requirements

To run this project successfully, you need:

* A device with a web browser (Chrome, Firefox, Edge, or Safari)
* All project files in the same folder:

  * `index.html`
  * `style.css`
  * `script.js`

No installation of software or packages is required.


## Step-by-Step Instructions to Run the Project

1. **Download or copy the project files**

   * Ensure that `index.html`, `style.css`, and `script.js` are saved in the same directory.

2. **Open the project**

   * Locate the `index.html` file.
   * Double-click it, or right-click and choose **Open with** → any web browser.

3. **Enter the bill amount**

   * Type a numeric value into the *Bill Amount* input field.

4. **Select a tip percentage**

   * Click one of the tip buttons (10%, 15%, or 20%).

5. **Enter the number of friends**

   * Input the number of people sharing the bill.

6. **Choose an option**

   * Click **Split** to divide the total amount equally among friends.
   * Click **Spin** to randomly select one friend to pay (this requires at least 2 friends).

7. **View the result**

   * The tip amount and total bill will be displayed at the bottom of the page.
   * If spinning is used, tap the wheel to rotate it.

---

## Project Files

* `index.html` – Defines the structure of the web page
* `style.css` – Handles layout, colors, and animations
* `script.js` – Contains the logic for calculations and interactions
